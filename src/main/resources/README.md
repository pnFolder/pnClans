## 🏦 Модуль 1: Казна (Bank / Treasury)

### 1.1 Пополнение и снятие средств
* **Статус:** ❌ В разработке / Не начато
* **Пермишены:** `clan.bank.deposit`, `clan.bank.withdraw`

#### 📝 Что нужно сделать:
- [ ] Команда `/clan bank deposit <сумма>` — пополнение казны из инвентаря игрока.
- [ ] Команда `/clan bank withdraw <сумма>` — снятие денег из казны клана.
- [ ] Проверка на отрицательные значения и вводимые символы (защита от дюпов/ошибок).
- [ ] Логирование операций (кто, сколько и когда взял/положил).

#### 💡 Заметки и идеи:
> Интегрировать через Vault API или экономический плагин сервера. Если денег у игрока недостаточно — выводить сообщение с ошибкой.
