# Каналы обновлений определяются только по тегу

Обновление упрощает логику каналов: pnClans больше не зависит от GitHub-флага Pre-release и определяет STABLE/BETA/ALPHA только по тегу версии.

## Новое
- Добавлена независимая от GitHub Pre-release классификация каналов обновлений.

## Улучшено
- Упрощено определение канала: `vX.Y.Z` считается STABLE, `vX.Y.Z-beta.N` — BETA, `vX.Y.Z-alpha.N` — ALPHA.
- GitHub-флаг `prerelease` теперь влияет только на отображение релиза на GitHub и не влияет на работу автообновления pnClans.

## Исправлено
- Исправлен случай, когда beta/alpha-релиз с правильным тегом игнорировался после ручного снятия GitHub-флага Pre-release.
- Исправлен случай, когда канал релиза мог зависеть одновременно от тега и состояния GitHub-флага.

## Важно
> `1.2.2-beta.2` публикуется как GitHub Prerelease для совместимости с уже выпущенным `1.2.2-beta.1`. Начиная с этой версии галочку Pre-release можно включать или выключать без влияния на канал обновления.
