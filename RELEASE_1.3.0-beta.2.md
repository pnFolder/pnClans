# v1.3.0-beta.2 — Добавлена команда расформирования клана

Версия позволяет лидеру расформировать клан командой без обязательного открытия меню.

## Добавлено

- Добавлена команда `/clan disband` для расформирования собственного клана с отдельным подтверждением через `/clan disband confirm`. Идею предложил <@857311104798294048>.
