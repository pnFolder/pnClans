# v1.3.0-beta.1 — Добавлен антифарм и расширена админка

Версия защищает клановые очки от PvP-фарма и даёт администраторам больше инструментов управления без ручного редактирования данных.

## Добавлено
- Добавлен `points.yml` с отдельными настройками антифарма, личных очков участников и хранения истории.
- Добавлены проверки антифарма для PvP: убийство соклановца, повторная жертва и cooldown, дневной лимит одной жертвы, двусторонний лимит пары игроков, опциональная проверка одинакового IP, минимальное игровое время и возраст аккаунта жертвы, diminishing returns, а также дневные лимиты очков игрока и клана.
- Добавлены публичные события `ClanPointsAntiFarmPreCheckEvent` и `ClanPointsAntiFarmResultEvent`, через которые сторонние плагины могут отменять проверку, обходить встроенные правила или изменять итоговую награду.
- Добавлена расширенная история операций с клановыми очками: ID транзакции, инициатор, цель, причина и связь с исходной операцией для rollback.
- Добавлены административные команды для просмотра истории очков, `reset`, `rollback`, просмотра anti-farm tracking и его очистки.
- Добавлено управление товарами через `/clan admin shop`: список, информация, создание, `addhand`, удаление, изменение цены, категории и слота, а также клонирование товара.
- Добавлено расширенное управление участниками через `/clan admin member`: список, информация, добавление, удаление, смена роли и безопасная передача лидерства.
- Добавлена точная выдача товара, созданного через `shop addhand`, с сохранением сериализованного `ItemStack`, включая метаданные предмета.

## Улучшено
- Anti-farm tracking и расширенная история очков сохраняются в обоих поддерживаемых хранилищах: JSON и SQLite, поэтому лимиты переживают перезапуск сервера.
- Обычные PvP-награды теперь проходят через единый anti-farm pipeline, при этом организованные клановые битвы остаются отдельным источником наград.
- Личные contribution points участника могут учитывать тот же anti-farm коэффициент, что и награда клана.
- Release workflow и Build Center assets переведены на канонические имена JAR с указанием продукта, версии, платформы и Java.
- AutoUpdater обновлён для новых имён JAR и поддерживает теги `rc.N` наряду с `alpha.N`, `beta.N` и stable.

## Важно
> Если включена проверка `sameIp`, сервер должен получать реальные IP игроков. При работе за Velocity/Bungee необходимо корректно настроить forwarding, иначе проверка одинакового IP может давать неверный результат.
