# v1.3.0-beta.3 — Настраиваемый фон интерфейсов

Версия позволяет менять декоративный фон клановых интерфейсов через `menus.yml`.

## Добавлено

- Добавлена общая настройка материалов и слотов декоративного фона GUI с возможностью полностью его отключить.

## Улучшено

- Фон подключается явно только в нужных интерфейсах, а функциональные элементы имеют приоритет над декоративными слотами.

## Совместимость

- Paper 1.21.11
- Java 21
- Java 25
