# pnClans

![Подсветка участников клана](.github/assets/v1.0.5/media_1786052370284.png)

> Продвинутая клановая система для Paper: GUI-управление, казна Vault, клановые дома, общий склад, прокачка, PvP-настройки, подсветка участников и публичный API для аддонов.

```text
 /\_/\   pnClans
( o.o )  Кланы, которые удобно настраивать и расширять.
 > ^ <
```

## Возможности

- Основное управление через меню: создание клана, участники, роли, настройки и действия клана.
- Казна с интеграцией Vault, историей операций и правами внутри клана.
- Несколько клановых домов, телепортация с задержкой и настройка доступных точек.
- Общий виртуальный сундук клана.
- Уровни и улучшения клана.
- Клановый чат, PvP между соклановцами, уведомления о входе и выходе.
- Настраиваемая подсветка соклановцев через PacketEvents.
- PlaceholderAPI, автообновление, SQLite или JSON-хранилище.
- Публичный API, система аддонов, внешние подкоманды и кнопки главного меню.

## Требования

- Сервер Paper `26.2`.
- Java `25`.
- Vault и плагин экономики нужны для создания клана за деньги и казны.
- PlaceholderAPI подключается автоматически, если установлен.

## Установка

1. Соберите проект командой `./gradlew.bat build` или возьмите готовый JAR из [Releases](https://github.com/pnFolder/pnClans/releases).
2. Поместите `pnClans-<version>-all.jar` в папку `plugins/` сервера.
3. При необходимости установите Vault и провайдер экономики.
4. Перезапустите сервер. В `plugins/pnClans/` будут созданы `config.yml`, `menus.yml` и `messages.yml`.

## Команды

Главная команда: `/clan`. Алиасы: `/c`, `/clans`.

| Команда | Назначение |
| --- | --- |
| `/clan` или `/clan menu` | Открыть главное меню клана. |
| `/clan create <название>` | Создать клан. Без названия открывает меню. |
| `/clan accept <клан>` | Принять приглашение в указанный клан. |
| `/clan deny <клан>` | Отклонить приглашение в указанный клан. |
| `/clan top` | Открыть список лучших кланов. |
| `/clan home [ключ]` | Телепортироваться к клановому дому. |
| `/clan sethome [ключ]` | Установить клановый дом при наличии внутрикланового права. |
| `/clan delhome [ключ]` | Удалить клановый дом при наличии внутрикланового права. |
| `/clan deposit` или `/clan withdraw` | Открыть меню казны. |
| `/clan chest` | Открыть общий сундук клана. |
| `/clan reload` | Перезагрузить конфигурации и открытые меню. Требует `pnclans.admin`. |

Команды домов, казны и сундука доступны, только когда соответствующий модуль включен в `config.yml`. Управление приглашениями, составом, ролями, настройками и роспуском клана доступно из главного меню.

## Права Bukkit

| Право | По умолчанию | Назначение |
| --- | --- | --- |
| `pnclans.use` | Все игроки | Базовый доступ к командам pnClans. |
| `pnclans.admin` | OP | Перезагрузка конфигурации через `/clan reload`. |

Права на действия внутри клана не являются Bukkit-permissions: лидер назначает их ролям в меню. Они включают доступ к казне, приглашениям, домам, складу, улучшениям, PvP, чату и подсветке.

## Конфигурация

| Файл | Содержимое |
| --- | --- |
| `plugins/pnClans/config.yml` | Модули, тип хранилища, экономика, обновления, роли и системные сообщения. |
| `plugins/pnClans/menus.yml` | Макеты GUI, слоты и доступные точки домов. |
| `plugins/pnClans/messages.yml` | Сообщения и цепочки действий: чат, звук, title, action bar и частицы. |

В `config.yml` можно независимо включать `homes`, `treasury`, `chest`, `upgrades` и `pvp`. Рекомендуемый тип хранения - `SQLITE`; также доступен `JSON`.

## PlaceholderAPI

При установленном PlaceholderAPI расширение `pnclans` регистрируется автоматически. Используйте плейсхолдеры в чатах, скорбордах, TAB и других совместимых плагинах.

| Плейсхолдер | Значение | Без клана |
| --- | --- | --- |
| `%pnclans_clan%` или `%pnclans_name%` | Название клана игрока. | `Нет` |
| `%pnclans_tag%` | Цветной тег `[Название]`. | Пустая строка |
| `%pnclans_role%` | Роль игрока в клане. | `Нет` |
| `%pnclans_level%` | Уровень клана. | `0` |
| `%pnclans_balance%` или `%pnclans_bank%` | Баланс казны клана. | `0` |
| `%pnclans_mmr%` | Рейтинг клана. | `0` |
| `%pnclans_kills%` | Убийства клана. | `0` |
| `%pnclans_deaths%` | Смерти клана. | `0` |
| `%pnclans_members%` | Участники в формате `онлайн/всего`. | `0/0` |

Для внутренних сообщений и настроек pnClans доступны аналогичные ключи в фигурных скобках: `{clan}`, `{clan_name}`, `{clan_tag}`, `{clan_role}`, `{clan_level}`, `{clan_balance}`, `{clan_mmr}`, `{clan_kills}`, `{clan_deaths}`, `{clan_members}` и `{player_name}`. Дополнительные контекстные ключи, например `{player}`, `{target}`, `{role}`, `{amount}`, `{cost}`, `{command}` и `{prefix}`, работают только в соответствующем сообщении или действии.

## Разработка и API

Собрать проект: `./gradlew.bat build`.

Запустить локальный Paper-сервер: `./gradlew.bat runServer`.

Внешние плагины должны зависеть от `pnClans` в своём `plugin.yml` и работать только с пакетами `ua.inventorytype.pnclans.api.*`. Примеры подключения, аддонов, команд и кнопок меню приведены в [ADDON_API.md](ADDON_API.md).
